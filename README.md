## 🚀 Project Overview
The project is a terminal-based calculator that allows users to perform basic arithmetic operations quickly and accurately. 

### Key Features:
* **Four Basic Operations:** Supports Addition, Subtraction, Multiplication, and Division.
* **Error Handling:** Built-in check to prevent crashes when dividing by zero (`ZeroDivisionError`).
* **Input Validation:** Automatically detects and alerts the user if an invalid menu choice is selected.

---

## 🛠️ How It Works
1. The user is presented with a clear menu of 4 operations.
2. The user inputs their selection (1-4).
3. The program requests two numbers from the user.
4. The requested operation is processed, and the final output is printed neatly on the screen.
